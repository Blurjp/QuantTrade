# Notification Setup Guide

## 📧 Email Setup (Gmail)

### Step 1: Create Gmail App Password

Gmail requires an "App Password" for automated emails (not your regular password).

1. **Go to Google Account Settings:**
   - https://myaccount.google.com/

2. **Enable 2-Factor Authentication:**
   - Security → 2-Step Verification → Turn on
   - (Required before creating App Password)

3. **Create App Password:**
   - Security → 2-Step Verification → App passwords
   - Or go directly to: https://myaccount.google.com/apppasswords
   - Click "Create app password"
   - App name: "QuantTrade"
   - Click "Create"
   - **Copy the 16-character password** (you won't see it again!)

4. **Update .env file:**
   ```bash
   SMTP_PASSWORD=xxxx xxxx xxxx xxxx  # Your 16-char app password
   ```

## 📱 SMS Setup (Twilio)

### Step 1: Create Twilio Account

1. **Sign up for Twilio:**
   - https://www.twilio.com/try-twilio
   - Free trial includes $15.50 credit
   - 1 SMS ≈ $0.0075 (can send ~2000 messages)

2. **Get your credentials:**
   - Go to: https://www.twilio.com/console
   - Copy "Account SID" and "Auth Token"

3. **Get a Twilio phone number:**
   - Go to: https://www.twilio.com/console/phone-numbers/search
   - Buy a number ($1/month)
   - Or use trial number (limited)

4. **Update .env file:**
   ```bash
   SMS_ENABLED=true
   TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   TWILIO_AUTH_TOKEN=your-auth-token
   TWILIO_PHONE_FROM=+1234567890  # Your Twilio number
   TWILIO_PHONE_TO=+0987654321    # Your mobile number
   ```

5. **Install Twilio library:**
   ```bash
   pip install twilio
   ```

### Step 2: Test SMS

```bash
python -m notifications.notification_manager
```

3. **Create webhook:**

   - Copy Webhook URL


## 🎯 Notification Thresholds

Control when you receive notifications:

```bash
# Minimum confidence to trigger notification (0-100)
NOTIFICATION_MIN_CONFIDENCE=70.0

# Minimum impact score to trigger notification (0-100)
NOTIFICATION_MIN_IMPACT=50.0
```

**Examples:**
- `70.0` = Only notify when confidence ≥ 70%
- `80.0` = Only high-confidence signals
- `60.0` = More notifications, lower quality

## 🔕 Quiet Hours

Prevent notifications during sleep:

```bash
# No notifications between these hours (24-hour format)
QUIET_HOURS_START=23  # 11 PM
QUIET_HOURS_END=7     # 7 AM
```

## ⚠️ Important Notes

1. **Gmail App Password:**
   - NOT your regular Gmail password
   - Must create App Password separately
   - Keep it secure!

   - Can only send to verified numbers

   - History tracked in `outputs/notification_history.json`
   - Quiet hours respected

   - Twilio: 1 SMS/second

   - Discord: 30 webhooks/minute

## 🔧 Troubleshooting

### Email not sending

**Error: "Authentication failed"**
- Check App Password is correct
- Ensure 2FA is enabled
- Try creating new App Password

**Error: "SMTP not connected"**
- Check SMTP_HOST and SMTP_PORT
- Try port 465 instead of 587
- Check firewall settings

### SMS not sending

**Error: "Twilio library not found"**
```bash
pip install twilio
```

**Error: "Number not verified"**
- Trial accounts need verified numbers
- Go to: https://www.twilio.com/console/phone-numbers/verified

### No notifications sent

**Check:**
1. Signal confidence ≥ NOTIFICATION_MIN_CONFIDENCE
2. Not in quiet hours
3. At least one channel enabled
4. Credentials are correct
